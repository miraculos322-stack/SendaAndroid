Accesos rápidos
Buses y paradas cercanas

Busca paradas registradas en OpenStreetMap alrededor de tu ubicación. Esto no confirma qué buses están circulando ni sus tiempos de llegada.

Pulsa «Buscar paradas» para consultar datos cartografiados.
Planifica tu viaje
La planificación de líneas, horarios y transbordos requiere datos oficiales de transporte que aún deben integrarse. Esta versión no inventa rutas de bus.

Cómo avanzar a rutas de transporte reales

Se necesita confirmar y obtener acceso a datos de rutas, paradas y horarios (por ejemplo, GTFS) de las autoridades u operadoras. Las posiciones en vivo requieren además una fuente compatible, como GTFS-Realtime o un servicio autorizado.

Modo Guardián

Prepara un aviso de viaje para una persona de confianza. En esta versión, el envío es manual; no hay seguimiento continuo ni alertas automáticas.

SENDA no es un servicio de emergencias. Comparte solo la información que quieras enviar y verifica que el mensaje se haya enviado.

Alertas comunitarias

Los reportes de esta versión se guardan únicamente en este dispositivo; todavía no se publican para otros usuarios.

Los reportes locales no son alertas verificadas.

Privacidad y permisos

La ubicación se solicita solo cuando pulsas una función que la necesita. Puedes escribir el origen manualmente si rechazas el permiso. El contacto de confianza se introduce manualmente y no se lee tu agenda.
